Public Online is unavailable. This static deployment has no hosted match service or database.

v14 supplies the durable backend foundation: protocol 3 authoritative snapshots, HMAC-hashed reconnect credentials, transactional command/reward idempotency, room leases with fencing tokens, restart recovery, retention and backup tooling, and a versioned PostgreSQL contract.

Owner infrastructure required

  • A managed PostgreSQL database with migrations and tested restore.
  • A TLS container host exposing wss://…/match, health, readiness and metrics.
  • A concrete PostgreSQL executor and production notification transport.
  • Unique instance IDs, lease timings, exact allowed origins, Telegram bot token and session-HMAC secrets.
  • Monitoring, backup retention, load/restart validation and an operational rollback owner.

Only after that service is verified should a client build set VITE_MATCH_MODE=online and VITE_MATCH_WS_URL. Practice remains private, local and playable without these services.
